# 3D 模型目录

请将小黄人机身外壳及相关结构件放在此目录（如 `.stl`、`.step`、`.3mf`）。

## 建议目录结构

```text
hardware/3d/
├── README.md
├── body/           # 主壳体（可按需分子目录）
├── eyes_mount/     # 屏幕支架（可按需分子目录）
└── ...
```

## 说明

- 文件名建议见名知意，例如 `minion_body_left.stl`。
- 若某套模型有固定采购或打印渠道，请在工程根目录 `README_zh.md` 材料清单「购买链接」列补充。
- 模型文件较大时，若仓库启用 Git LFS，建议对大文件使用 LFS 管理。
