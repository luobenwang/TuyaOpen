# RGB LED 控制功能说明

## 功能概述

本项目集成了WS2812B RGB LED控制功能，通过P10引脚控制RGB LED的颜色和亮度。

## 硬件连接

### WS2812B RGB LED连接
- **VCC**: 连接到3.3V电源
- **GND**: 连接到地线
- **DI**: 连接到T5AI开发板的P10引脚（GPIO 10）

### 注意事项
- 确保电源电压为3.3V（不要使用5V）
- 建议在VCC和GND之间添加100μF电容
- 如果使用多个LED串联，确保总电流不超过电源能力

## 软件功能

### 1. 亮度控制
- 亮度滑条：0-100%可调
- 实时调节LED亮度
- 亮度值显示在界面上

### 2. 颜色控制
- 色相滑条：0-360°可调
- 支持全色谱颜色选择
- 实时预览颜色效果

### 3. 界面特性
- 颜色预览区域：实时显示当前选择的颜色
- 状态指示：显示LED连接和初始化状态
- 返回按钮：可返回聊天主界面

## 使用方法

### 1. 进入RGB控制界面
- 在主聊天界面点击"RGB控制"按钮
- 系统会自动初始化RGB LED

### 2. 调节亮度
- 拖动亮度滑条（0-100%）
- 亮度值实时显示
- LED亮度立即响应

### 3. 调节颜色
- 拖动色相滑条（0-360°）
- 颜色预览区域实时更新
- LED颜色立即响应

### 4. 返回主界面
- 点击顶部"返回"按钮
- 返回聊天主界面

## 技术实现

### 1. 驱动层
- **文件**: `src/display/rgb_led/rgb_led.c`
- **协议**: WS2812B单线协议
- **时序**: 精确的纳秒级时序控制
- **GPIO**: 使用P10引脚（GPIO 10）

### 2. UI层
- **文件**: `src/display/ui/ui_rgb_control.c`
- **框架**: LVGL v8
- **控件**: 滑条、标签、预览区域
- **事件**: 滑条值变化事件处理

### 3. 集成方式
- 在主界面添加切换按钮
- 支持界面间无缝切换
- 保持LED状态

## 编译配置

### 1. 启用功能
在配置文件中设置：
```
CONFIG_ENABLE_GUI_RGB_CONTROL=y
```

### 2. 依赖关系
RGB控制功能依赖于聊天机器人UI：
```
CONFIG_ENABLE_GUI_CHATBOT=y
```

### 3. 源文件
- `src/display/rgb_led/rgb_led.c` - 驱动实现
- `src/display/rgb_led/rgb_led.h` - 驱动头文件
- `src/display/ui/ui_rgb_control.c` - UI实现
- `src/display/ui/ui_rgb_control.h` - UI头文件

## 故障排除

### 1. LED不亮
- 检查电源连接（3.3V）
- 检查P10引脚连接
- 检查LED型号是否为WS2812B

### 2. 颜色异常
- 检查数据线连接
- 确认LED数量配置正确
- 检查电源稳定性

### 3. 编译错误
- 确认所有依赖文件存在
- 检查CMakeLists.txt配置
- 验证Kconfig设置

## 注意事项

1. **电源要求**: 确保3.3V电源稳定
2. **电流限制**: 单个LED约60mA，注意总电流
3. **时序要求**: WS2812B对时序要求严格
4. **温度控制**: 长时间使用注意散热
5. **代码优化**: 避免在中断中调用LED控制函数
