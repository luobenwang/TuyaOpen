# 表情符号显示问题修复

## 🐛 问题描述

用户反馈：☀️ 这个表情符号无法在设备上正确显示。

## 🔍 问题原因

### 根本原因
设备不支持Unicode表情符号显示，可能的原因：
1. **字体不支持**：设备字体不包含Unicode表情符号
2. **编码问题**：设备字符编码不支持表情符号
3. **显示限制**：小屏幕设备可能不支持复杂字符显示
4. **系统限制**：嵌入式系统可能不支持Unicode表情符号

### 影响范围
- 天气时钟中的天气图标显示
- 所有使用Unicode表情符号的地方

## 🔧 修复方案

### 修改前的问题
```c
snprintf(date_weather_str, sizeof(date_weather_str), "%s  ☀️ 22°C", date_str);
// 显示: 01/01  ☀️ 22°C  (表情符号无法显示)
```

### 修改后的解决方案
```c
snprintf(date_weather_str, sizeof(date_weather_str), "%s  SUN 22C", date_str);
// 显示: 01/01  SUN 22C  (ASCII字符正常显示)
```

## ✅ 修复内容

### 1. 替换Unicode表情符号
- **☀️** → **SUN** (晴天)
- **22°C** → **22C** (温度，移除度数符号)

### 2. 修改的位置
1. **定时器回调函数**：`__weather_clock_timer_cb()`
2. **初始化函数**：`__ui_weather_clock_init_160x80()`
3. **显示函数**：`ui_weather_clock_show()`
4. **天气更新函数**：`ui_weather_clock_update_weather()`

### 3. 具体修改
```c
// 修改前
"01/01  ☀️ 22°C"

// 修改后
"01/01  SUN 22C"
```
