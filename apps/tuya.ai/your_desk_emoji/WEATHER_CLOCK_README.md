# 天气时钟功能说明

## 功能概述

天气时钟功能为桌面表情机器人添加了实用的时钟显示，支持实时时间更新、日期显示和天气信息展示。

## 主要特性

### 1. 启动时显示时钟
- 系统启动后自动显示天气时钟界面
- 无需手动操作，开机即用

### 2. 实时时间更新
- 时钟每秒自动更新时间显示
- 使用系统时间，支持网络时间同步
- 显示格式：HH:MM:SS（24小时制）

### 3. 日期显示
- 显示当前日期，格式：MM/DD
- 与时间同步更新

### 4. 天气信息显示
- 显示天气图标和温度
- 格式：☀️ 22°C
- 支持多种天气图标：☀️ ⛅ 🌧️ ❄️ 🌪️

### 5. 手势交互
- 检测到手势时自动切换到表情轮播模式
- 表情轮播10秒后自动返回天气时钟
- 支持所有现有手势：上下左右、旋转、点头等

## 技术实现

### 文件结构
```
src/display/ui/
├── ui_weather_clock.h          # 天气时钟头文件
├── ui_weather_clock.c          # 天气时钟实现

include/

src/

```

### 核心组件

#### 1. UI组件
- `WEATHER_CLOCK_UI_T`: 天气时钟UI结构
- `WEATHER_CLOCK_T`: 天气时钟管理结构

#### 2. 主要函数
- `ui_weather_clock_init()`: 初始化天气时钟UI
- `ui_weather_clock_show()`: 显示天气时钟
- `ui_weather_clock_hide()`: 隐藏天气时钟
- `ui_weather_clock_update_weather()`: 更新天气信息

#### 3. 显示消息类型
- `TY_DISPLAY_TP_WEATHER_CLOCK_SHOW`: 显示天气时钟
- `TY_DISPLAY_TP_WEATHER_CLOCK_HIDE`: 隐藏天气时钟
- `TY_DISPLAY_TP_WEATHER_CLOCK_UPDATE_WEATHER`: 更新天气信息

## 使用方法

### 1. 系统启动
系统启动后会自动显示天气时钟，无需额外操作。

### 2. 手势交互
- 做出任何手势动作
- 系统自动切换到表情轮播模式
- 10秒后自动返回天气时钟

### 3. 天气信息更新
```c
// 更新天气信息
char weather_data[] = "☀️,25°C";
app_display_send_msg(TY_DISPLAY_TP_WEATHER_CLOCK_UPDATE_WEATHER, 
                    (uint8_t *)weather_data, strlen(weather_data));
```

### 4. 手动控制显示
```c
// 显示天气时钟
app_display_send_msg(TY_DISPLAY_TP_WEATHER_CLOCK_SHOW, NULL, 0);

// 隐藏天气时钟
app_display_send_msg(TY_DISPLAY_TP_WEATHER_CLOCK_HIDE, NULL, 0);
```

## 配置选项

### 字体配置
- 时间显示：30px字体（font_puhui_30_4）
- 日期天气：14px字体（font_puhui_14_1）
- 状态栏：系统默认字体

### 更新间隔
- 时间更新：1000ms（1秒）
- 表情轮播返回：10000ms（10秒）

### 屏幕支持
- 主要支持：160×80像素
- 兼容支持：128×64像素

## 故障排除

### 常见问题

1. **天气时钟不显示**
   - 检查显示系统是否正确初始化
   - 确认屏幕分辨率是否支持

2. **时间不更新**
   - 检查系统时间是否正确设置
   - 确认网络时间同步是否正常

3. **手势切换不工作**
   - 检查手势检测模块是否正常
   - 确认定时器功能是否正常

### 调试信息
启用调试日志查看详细信息：
```c

PR_DEBUG("Weather updated to: %s", weather_data);
```
